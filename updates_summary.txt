RESUMO DAS ATUALIZAÇÕES - PROJETO SERVIGO

1. Análise Geral
   - O projeto já possuía 4 microsserviços (+ API Gateway) criados.
   - O problema principal detetado foi a falta de organização do código (tudo num ficheiro só) e a falta de padronização.

2. Refatorização para Arquitetura em Camadas
   Para cada serviço, o código foi separado em pastas lógicas para facilitar a manutenção e cumprir os requisitos:
   - src/config: Configuração da Base de Dados.
   - src/models: Esquemas de Dados (Sequelize para SQL, Mongoose para MongoDB).
   - src/controllers: Lógica de tratamento dos pedidos HTTP.
   - src/services: Lógica de negócio (regras, cálculos).
   - src/routes: Definição das rotas da API.

3. Detalhes por Serviço

   A. Auth Service (Node.js)
      - Tecnologia: Express + Sequelize (PostgreSQL).
      - Estado: Refatorizado completamente.
      - Funcionalidades: Registo e Login com JWT.

   B. Catalog Service (Python)
      - Tecnologia: FastAPI + SQLAlchemy (PostgreSQL).
      - Requisito "Poliglota": Cumprido (Python vs Node.js).
      - Estrutura: Adaptada para o padrão Python (app/models.py, app/schemas.py, app/crud.py).
      - Docker: Atualizado para correr o novo formato da aplicação.

   C. Booking Service (Node.js)
      - Tecnologia: Express + Mongoose (MongoDB).
      - Estado: Refatorizado completamente.
      - Funcionalidades: Criar, Listar e Atualizar Reservas.

   D. User Service (Node.js + GraphQL)
      - Tecnologia: Express + Apollo Server + Mongoose (MongoDB).
      - Requisito "GraphQL": Cumprido.
      - Refatorização: Separação clara entre Schema (typeDefs), Resolvers e Lógica de Serviço.

5. Frontend (Nova Implementação)
   - Criada uma interface unificada e moderna (HTML5 + CSS3).
   - Ficheiros criados:
     - index.html: Página inicial com navegação.
     - styles.css: Estilos partilhados (design limpo, cores harmoniosas).
     - login.html: Autenticação (Login e Registo) ligada ao Auth Service.
     - catalog.html: Listagem e criação de serviços (Catalog Service).
     - bookings.html: Gestão de reservas (Booking Service), com lógica para Clientes e Profissionais.
     - profile.html: Visualização de perfil usando GraphQL (User Service).

6. Outras Mudanças
   - Adicionadas dependências do Swagger (swagger-ui-express, swagger-jsdoc) nos ficheiros package.json de todos os serviços Node.js, preparando o terreno para a documentação automática.
   - Dockerfiles ajustados onde necessário.
